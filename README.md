For this assignment, I created a PostgreSQL database on Render and set up a `users` table to store user information. I then used Node.js and Express to build a REST API with a `GET /users` endpoint that retrieves all users from the database and returns them in JSON format. I used the `pg` package to connect my server to PostgreSQL and `dotenv` to keep my database credentials separate from my code. I also connected my database to DBeaver to make it easier to view and manage the data, and tested my API locally in my browser to make sure everything worked.
